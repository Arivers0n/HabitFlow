# HabitFlow

Трекер привычек для iPhone и iPad: формируй полезное и отказывайся от вредного.

- **Формирую** — вода, спорт, чтение, медитация. Отметка одним касанием или объём («+250 мл»), расписание: каждый день, N раз в неделю или по дням. Серии, календарь, графики по неделям.
- **Отказываюсь** — курение, алкоголь, сладкое. Живой счётчик без срыва, запись срыва с датой, количеством и причиной. Серия сбрасывается, рекорд и история остаются. Считает, сколько не употреблено и сэкономлено.
- **Награды** за 1, 3, 7, 14, 21, 30, 60, 90, 180 и 365 дней, конфетти и вибрация. Длинные серии открывают иконки Бронза, Серебро, Золото и Алмаз.
- **Кастомизация** — темы-пресеты и свои темы, акцент, фон (Глубина, Полночь, Аврора, Графит, OLED), стеклянные / сплошные / контурные карточки, шрифт, светлая и тёмная схема, плотность, порядок блоков, тон текстов, 14 иконок приложения, своя библиотека причин срывов.
- Резервная копия в JSON и восстановление.

## Установка

1. **Releases** → `latest` → скачать `HabitFlow.ipa` (или **Actions** → последний зелёный запуск → артефакт).
2. Подписать своим сертификатом (ESign, Sideloadly, AltStore) и установить.

Каждый пуш в `main` собирает новую версию.

## Устройство кода

```
HabitFlow/
├─ Domain/        чистый Swift: модели, StreakEngine, RewardEngine, StatsEngine
├─ Data/          SwiftData-модели, HabitStore (все изменения), уведомления, вибрация, бэкап
├─ DesignSystem/  Appearance (все настройки вида), карточки-стекло, фоны, иконки
├─ Features/      экраны: Today, Detail, Editor, Relapse, Progress, Settings
└─ App/           точка входа и корневой экран
Tests/DomainTests  тесты логики стриков, запускаются в CI без симулятора
```

Тесты логики локально:

```
swiftc HabitFlow/Domain/*.swift Tests/DomainTests/main.swift -o t && ./t
```

Проект описан в `project.yml` (XcodeGen): `brew install xcodegen && xcodegen && open HabitFlow.xcodeproj`.
