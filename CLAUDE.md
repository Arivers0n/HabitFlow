# HabitFlow — памятка для Claude Code

Личное iOS-приложение: трекер привычек (полезные + вредные), напарник-питомец, ИИ, друзья. Владелец: Arivers0n. **Отвечать всегда по-русски.**

## Среда и ограничения
- У владельца **нет Mac**. Сборка только через GitHub Actions (macOS-раннер), результат — неподписанный `HabitFlow.ipa`, который он подписывает в ESign и ставит на iPhone 16 Pro Max / iPad.
- `main` → сборка + релиз `latest` (HabitFlow.ipa). `dev` → сборка + скриншоты симулятора, без релиза.
- Локально на Linux можно проверить только чистый домен: `swiftc HabitFlow/Domain/*.swift Tests/DomainTests/main.swift -o /tmp/t && /tmp/t` (сейчас 159 проверок, все зелёные). SwiftUI/SwiftData локально не собрать — любую правку проверять сборкой в CI.
- Проект генерируется XcodeGen из `project.yml` (iOS 17+, SwiftUI + SwiftData + Observation, bundle `com.ariverson.habitflow`, схема URL `habitflow://`, версия 1.1 build 2).
- Подводный камень компилятора Swift: сложные выражения во View → «unable to type-check in reasonable time». Дробить на маленькие типизированные куски.

## Архитектура (слои, зависимость только вниз)
- `Domain/` — чистый Swift без UI/SwiftData: DomainModels, StreakEngine, RewardEngine, StatsEngine, CompanionEngine (XP/уровни/настроение), CompanionPhrases, Formatting. Тесты: `Tests/DomainTests/main.swift`.
- `Data/` — SwiftData-модели (Habit, CheckIn, Relapse, Resist), HabitStore (все изменения идут через него), BackupService, Services (вибрации, уведомления), SyncEngine/SyncCodec/PrefSync, AIService/AICoach, AppRouter (вкладки, deep links, debug-ссылки), CompanionCatalog/CompanionManager, Keychain.
- `DesignSystem/` — Appearance (все настройки вида, пресеты, Palette, Motion), Components (карточки со стеклом), AppBackground, AppIcons (14 иконок).
- `Features/` — Today, Detail, Editor, Relapse, Progress, Settings, Account, AI, Friends, Shared, Companion (+ Pet/: PetShaders.metal, MotionTracker, PetSim, Egg3DView).
- `HabitFlowWidgets/` — расширение виджетов (WidgetKit, AppIntent со слотом «Виджет 1…6»). Берёт из основного кода только `Domain/`, `Data/WidgetStorage.swift` и `DesignSystem/WidgetRenderer.swift` (см. `project.yml`).
- `App/` — HabitFlowApp (AppData, быстрые действия, онбординг, клавиатурные сочетания), Intents (Siri).
- `server/` — модуль для PocketBase-сервера Копилки (коллекции hf_docs/hf_circles/hf_profiles, маршруты `/api/hf/*`) + `install-habitflow.sh` (ставится одной командой на VPS).
- **Правило из ТЗ:** перед новой функцией сначала коротко описать, как она вписывается в архитектуру; логика в Domain/Data, UI тонкий.

## Ключевые решения
- Два вида привычек: «отказ» (живой счётчик без срыва, срыв = дата/количество/триггер/заметка, рекорд и история остаются) и «формирование» (ежедневно / N в неделю / по дням, объёмные цели, календарь, награды за 1…365 дней).
- XP **не хранится**, пересчитывается из истории: +10 привычка, +30 идеальный день, +15 чистый день, +5 «устоял» (макс. 3/день). Уровень n требует 60·n(n−1)/2 XP. Стадии: яйцо (ур.1), малыш (2–4), подросток (5–9), взрослый (10+). Настроения: happy/calm/sad/caring (срыв <24 ч → caring).
- Питомцы: 14 персонажей (11 пользовательских картинок + мои Бульк/Уголёк/Тим). Яйцо — SceneKit 3D (PBR, трещины на 45/75/92 %, вылупление с осколками). Остальные — «живые картинки» 2.5D: Metal-шейдеры `petJelly`/`petGloss`, параллакс от CoreMotion, PetSim (погладить/щекотать/поднять и бросить/покормить/сон).
- Синхронизация: общий аккаунт с Копилкой (PocketBase), last-write-wins по `cts`, tombstones для удалений, `dirty`-метки, PrefSync для настроек. Вход: почта / Google / Яндекс / Apple через общий OAuth-callback `https://SERVER/api/kp/oauth-callback` → `koshelek://oauth` (ASWebAuthenticationSession со схемой `koshelek`). Адрес сервера по умолчанию: `https://2-27-25-140.sslip.io:8443`.
- ИИ: через `/api/kp/ai` на сервере (ключ не в приложении) либо свой ключ/шлюз в Keychain.
- Скриншоты в CI: аргументы запуска `-hfShot egg|stress`, `-hfShotCharacter`, `-hfOpen <путь>`, debug-ссылки `habitflow://debug/hatch|levelup|resist|chat`.

## Как работать
- Правки → `git push origin dev` → смотреть Actions и скриншоты → когда зелёное, мёржить в `main`.
- Не ломать обратную совместимость бэкапа (BackupService) и SwiftData-моделей: новые поля только с значением по умолчанию.
- Сначала описать план пользователю, потом писать код; результат показывать скриншотами из CI.

## Виджеты (добавлено)
- Конструктор: Настройки → «Виджеты» (`habitflow://settings/widgets`). 6 слотов × 6 размеров (малый/средний/большой, круг/прямоугольник/строка на экране блокировки). Фон, раскладка (столбиком / главный слева / главный сверху), блоки: кольцо дня, «3 из 5», процент, серия без срыва, список отказов, серия привычки, уровень, фраза напарника, следующая привычка, неделя, дата, приветствие, питомец, свой текст. У блока: шрифт, размер, толщина, цвет, непрозрачность, интервал, подписи, форма. На экране блокировки цвета задаёт система.
- Domain: `WidgetConfig` (типы, границы значений `validated()`, пресеты), `WidgetSnapshot` (снимок + `WidgetSnapshotBuilder`, числа те же, что в кольце «Сегодня») и `WidgetContent` (что показывает блок; устаревший снимок показывает «—», дни без срыва догоняются). Тесты в `Tests/DomainTests` (289 проверок).
- Data: `WidgetStore` (конфиги в UserDefaults, синхронизация через PrefSync, поле `widgets` в бэкапе — необязательное; снимок обновляется из `HabitStore.save()` с задержкой 1 с, при входе и выходе из приложения), `WidgetStorage.swift` — общий канал данных.
- Канал данных: сначала App Group (имя берётся из встроенного профиля, если ESign переименовал), иначе запасной — общая группа связки ключей `<команда>.habitflow.shared`. Если не работают оба, виджет показывает пример с жёлтым значком; в конструкторе раздел «Связь с виджетом» показывает, какой канал работает.
- Рендерер `DesignSystem/WidgetRenderer.swift` общий для виджета и предпросмотра в конструкторе.
- Снимки CI: `-hfWidgetFamily small|medium|large|lockCircular|lockRectangular|lockInline`, `-hfWidgetSlot 1…6` (вместе с `-hfShot`, `-hfOpen settings/widgets`).
- Неподписанный `.ipa` не несёт никаких прав (проверено по бинарникам). App Group и keychain-access-groups добавляет ESign из профиля сертификата.
